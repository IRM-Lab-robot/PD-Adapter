## Overview
 
Underactuated dexterous hands cannot directly execute the full-joint grasps produced by existing grasp generators. **PD-Adapter** adapts such grasps to underactuated hands without modifying the grasp generator, by learning command-space initializations for local grasp sampling from physics-guided teacher search. Evaluated on three underactuated hands (Inspire RH56, PSYONIC Ability, SCHUNK SVH) and on a real Inspire RH56 hand. Please refer to the paper for details.
